مشروع Landing Page جاهز للتعديل.
الملفات:
index.html = الصفحة والمحتوى والصور
style.css = التصميم
script.js = النموذج + PSO2026 + واتساب + UTM/GCLID
google-apps-script.js = ربط Google Sheets

لتعديل الصور: افتح index.html وابحث عن placehold.co واستبدل الروابط بروابط صورك.

لربط Google Sheets:
1- أنشئ Google Sheet.
2- Extensions > Apps Script.
3- الصق google-apps-script.js.
4- Deploy > New deployment > Web app.
5- Execute as: Me.
6- Who has access: Anyone.
7- انسخ الرابط.
8- ضعه في script.js مكان PASTE_YOUR_GOOGLE_APPS_SCRIPT_URL_HERE.

مهم لسلة:
هذا المشروع Landing Page HTML/CSS/JS مستقل. سلة لا ترفع مجلد HTML المستقل كاستضافة عادية. إذا كان المطلوب إدخاله داخل ثيم سلة، يتم نقل HTML/CSS/JS إلى بنية الثيم أو قسم HTML مخصص حسب الثيم المستخدم. الصور والنصوص يمكن تعديلها من الكود أو تحويلها لاحقاً إلى إعدادات قابلة للتعديل من محرر الثيم.
